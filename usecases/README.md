
## Use cases

This repository contains fully functional, standalone implementations of the following use cases on Amazon DocumentDB:
  
- [Product catalog](./product_catalog) - product catalog use case implementation
- [Media asset workbench](./media_asset_workbench) - media asset processing pipeline using Amazon S3 Files
- [Social Media](./social_media) - social media use case
- [Personalization profile](./personalization) - retail shopper profile with capped behavior history and category affinities
- [Customer 360 profile](./customer_360) - financial services unified customer profile with bounded recent interactions
- [Clinical trial protocol](./clinical_trial_protocol) - healthcare and life sciences trial design metadata with amendment history
- [Player profile & inventory](./player_profile) - games player profile with stackable inventory and a top-N leaderboard
- [Retail replenishment](./retail_replenishment) - recurring purchase pattern detection and reorder recommendations
